`source-snapshot/` preserves the original project-relative paths. It is a historical working snapshot, not a tested release. Existing version folders are retained to avoid guessing the latest implementation. `SOURCE-MANIFEST.json` records byte sizes and SHA-256 hashes.

Files with unresolved secret-pattern findings are held locally. This is not a full backup; excluded originals remain on the user's computer. Some snapshots need excluded assets, public keys or dependencies to run.
